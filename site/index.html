Good to know

Questions

Is it really free?

Yes. Ironbooks is open source under the MIT license. There is no subscription, no paid tier and no account to create.

What do I need to run it?

A 64-bit Windows 10 or 11 PC. Use the installer, or the portable version if you'd rather not install anything. On a Mac or Linux you can build it from the source code.

Why does Windows warn me when I install it?

The installers are signed by RealDealCPA.Ai LLC, with a certificate issued by Microsoft. Windows SmartScreen also weighs how many people have downloaded a publisher's files, so it can still warn for a while after a publisher starts signing. Check that the publisher reads RealDealCPA.Ai LLC, then choose More info and Run anyway. Every installer is built and signed by GitHub Actions from the public source code.

How do updates work?

An installed copy checks for new versions and updates itself after asking you. You can turn update checks off in Privacy & Network.

Does anything leave my computer?

Only what you turn on. Update checks (the app version and platform) are the one connection on by default. The privacy policy lists everything else and the switch for each.

Can more than one person use the books?

Yes. Ironbooks hosts the company file for your team over your office network or a Tailscale network, with users, roles and permissions.
